## 二、怎么注册、怎么登录

1. 在浏览器打开 `http://127.0.0.1:8080/`。
2. 第一次使用，点 **「第一次使用」**。
3. 填用户名（2—24 个字，中文、字母、数字、下划线、短横线都可以）和密码（至少 6 位），再输一遍密码。
4. 点 **「创建并进入」**。系统会自动生成这个人的个人词库，并放入一份初始高频词副本。
5. 以后再打开，点 **「登录」**，填同一个用户名和密码即可。换电脑、换浏览器也一样，进度跟着账号走。

- 不需要手机号、邮箱验证码、第三方登录。
- 没有公共词库。每个人只能看到、修改自己的词库。
- 没有预置演示账号。验收时可自行注册；同一个浏览器可以退出后换另一个用户名注册，验证两边互不影响。

> 密码忘记后无法通过邮箱或手机找回（V1 没有这些信息）。登录状态下可以在「设置 → 修改密码」。请把密码记好。

## 三、初始词库：条数与来源

### 3.1 数量

| 类别 | 条数 |
|---|---:|
| 成语 | 32 |
| 实词 | 28 |
| **合计** | **60** |

另有 **4 个预置易混组，每组 10 个词**：

1. 成语 · 快慢与成效
2. 成语 · 态度与评价
3. 实词 · 公文与日常
4. 实词 · 易错搭配

每个新用户首次进入时，系统复制同一份初始内容到他的个人词库；此后增删改只影响本人。词条包含：类型、词语、释义、例句、来源、近义/易混词、干扰词。

### 3.2 选词来源

- 选词范围参照 **2021—2025 年国家公务员考试、多省公务员联考、部分省考，以及事业单位公开招聘分类考试** 言语理解与表达公开真题中反复出现的成语、实词。
- 选词依据是公开可检索的真题高频词整理和公开语料，不使用付费题库，不爬取、不复制整套课程或题库。
- 释义用现代汉语重新表述；例句以公开真题的常见语境为参照 **改写或编写**，不是整套真题原文的逐字复制。每个词条都写了来源说明，界面上可查看。
- 公开参考入口（仅作为可检索来源示例）：
  - 国家公务员局考试录用专题：http://bm.scs.gov.cn/
  - 人民网教育频道：http://edu.people.com.cn/
  - 新华网：http://www.news.cn/

### 3.3 已知差距

任务书写的是「句子尽量用真题原句」。V1 的 60 条例句 **没有逐字引用完整真题原句**：公开完整真题往往需要登录、付费或不允许整卷转载，本轮没有去复制付费题库。现有例句是对公开真题语境的改写/自编，已在每条「来源」中说明。下一步如果要提高真题原句比例，需要文轩提供可合法使用的讲义，或授权逐条核对公开来源，再替换。

## 五、离线与同步怎么验

### 5.1 跨设备同步（在线）

1. 在浏览器 A 注册账号，学 1—2 个词，或新增一个词。
2. 等右上角显示 **「已保存」**（通常 1 秒内；离线会显示「稍后自动保存」）。
3. 换另一个浏览器或无痕窗口，打开同一地址，用同一个用户名和密码登录。
4. 在「我的词库」和「学习统计」里应看到同一份词、学习记录和连续天数。

说明：同步会在每次操作后自动进行，页面重新可见、恢复网络时也会补传，并每 45 秒检查一次。不是实时推送，换设备后通常等 1—3 秒或刷新即可看到。

### 5.2 离线

1. 第一次登录后，在应用保持打开、网络正常时多等几秒，让浏览器把页面缓存好（HTTPS 或 localhost 才可以；普通 HTTP 局域网地址不具备完整离线重开能力）。
2. 断网（关闭 Wi-Fi / 开发者工具设为 Offline），刷新页面。应能看到登录状态、词库和进度，右上角显示 **「离线 · 稍后自动保存」**。
3. 断网时学习、添加词语。所有操作先记录在这台设备。
4. 恢复网络。页面会自动补传，右上角回到 **「已保存」**。换设备登录，能看到断网期间的学习和新增词。

本次实际测试：Service Worker 已控制页面后，断网重载可打开；离线新增「离线试词」、完成一轮句中选词；恢复网络后状态变为「已保存」，第二个浏览器登录同一账号后能搜到「离线试词」，并且到期时间已更新。

### 5.3 数据备份

- 设置 → 账号 → **「下载备份」**：下载一个文件，包含当前词库、进度、统计和待保存条数；**不含密码**。
- 服务端每天第一次写入前，会自动保留一份 `data/backups/app-data-YYYY-MM-DD.json`。
- 没有「一键清空」按钮；删除词语、分组、错词都是软删除，学习历史保留。

### 6.2 为什么没有直接给长期公网地址

这个应用需要「登录 + 跨设备同步 + 离线补传」，单纯把页面放到 GitHub Pages 这类纯静态托管上不够，必须有能保存账号和进度的小后端。

本轮实际尝试了匿名免费隧道，但都不适合作为正式地址：

- **Cloudflare Quick Tunnel**：本环境封了它需要的出站 7844 端口，连不上 Edge，失败。
- **Serveo**：无需账号，但免费匿名隧道会先插入「不要输入密码」的浏览器警告页；即使加参数跳过，也会间歇性 502、数分钟内断线，不能用于让考生输入密码。
- **localhost.run**：无需账号，但免费匿名地址持续几分钟就断开，且提示要注册账号才能获得更久域名。

这些服务要么不稳定、要么会插入安全警告，不能作为「给其他考生用」的长期入口；继续强行使用会让用户遇到打不开、进度送不上去或安全提示，所以本轮没有把它写成交付地址。

## 八、已知限制

1. **没有长期公网地址**，原因和待拍板方案见第六节；本机地址随服务进程存在。
2. **例句不是逐字真题原句**，是公开真题语境改写/自编；后续可替换，见第三节。
3. **忘记密码无法自助找回**：没有手机/邮箱，只能重新注册（旧账号数据仍在，但无法登录）。登录后可改密码。
4. **练习进行到一半刷新页面，本轮队列不保留**；已经点过「完成」的词和学习记录已保存，刷新后从新的计划继续。错词、进度不会丢。
5. **同步不是实时协同**：每次操作后、页面重新可见、恢复网络时以及每 45 秒尝试；两台设备同时改同一个词时，以服务端最后收到的修改为准。
6. **导入格式**：暂不支持直接读 `.xlsx`，需要从 Excel 另存为 CSV/TXT；冲突按「同一类型 + 字面完全一样」判断。
7. **离线重开需要 HTTPS 或 localhost**。普通局域网 `http://IP` 下页面打开期间可以学，但关掉标签页后重新打开需要网络；这是浏览器对 Service Worker 的安全限制，不是应用收费点。
8. **本机服务是单机 JSON 存储**，适合个人/小范围使用；没有做多服务器集群、对象存储、管理员后台或数据恢复中心。正式多人使用前建议按第六节选定托管方案。
9. **公网演示如果使用第三方隧道，会经过第三方**。本轮没有交付这样的地址；不要在本机 HTTP 或不可信隧道上输入重要密码。
10. 没有做推送提醒、短信、微信提醒：每日计划需要打开页面查看。
