# DSH-TASK-V1：言语理解「成语与实词」记忆系统

下达：文轩经 DSH云端官 · 2026-11-10
执行方：dsh（本 bot 只布置与验收，不写业务代码）
工作目录：`/workspace/dsh-projects/yanyu-cishu/`（新建独立项目，不要并入公考错题本）

## 目标
做一款公务员、事业单位考试「言语理解」板块的成语与实词记忆网页系统。给文轩和其他考生用。第一版做到下面「最小可交」即停，不扩范围、不另起品牌包装。

## 已拍板需求（必须遵守）

### 使用者与账号
- 其他人也可以用。每人一份完全独立的个人词库与学习进度，互不影响。不要做「总词库 / 公共词库」。
- 登录只要用户名 + 密码，不要手机号、邮箱验证码或第三方登录。
- 进度跟人走：换电脑或换浏览器，登录后进度要在。第一次登录后，没网也能继续学习；重新有网时自动把进度同步回去。

### 词库
- 新用户第一次进入：系统把他的个人词库初始化为「一份初始高频词副本」，之后只能改自己的这份。
- 初始词范围：近五年国考、省考、事业编真题中的高频成语和高频实词（第一版先做一份能用的，不必宣称穷尽，但成语和实词都要有；在验收里注明来源与大约条数）。
- 支持后续导入讲义/词表：只进入自己的词库。冲突规则：成语、实词都是「字面完全一样」才算冲突；只拦住冲突的那几条，其余照常导入。
- 使用者可在自己的词库里增删改（释义、例句、易混组等）。

### 学习计划
- 系统按计划推送「今日新学 + 到期复习」。
- 每日新学数量有默认上限（默认 20，使用者可改）。
- 到期复习提供两种模式，使用者可切换：① 当天清完；② 可以留到后面。
- 成语和实词：可以分开练，也可以混在同一轮。

### 练习
- 两种模式由使用者二选一（不要强制每个词两种都做）：
  1. 先自己想再揭晓。揭晓后三种检查都要有：自己点「认识 / 模糊 / 忘记」、默写、选择近义项。第一版三种都要能用到，可按词轮换或连续出现，不能缺一种。
  2. 在句子里选词。句子尽量用真题原句；选项里要故意放易混词作干扰。
- 另做「易混组成组对比练习」：一组大约 10 个词。系统先预置常见易混组，使用者也能自己补充。

### 其他
- 需要：错词本、每日打卡、简单统计（至少包括连续学习天数、待复习数）。
- 与现有「公考错题本」是两个独立工具，不要打通、不要复用其账号或数据。
- 用浏览器打开即可，不必做成必须安装的原生 App。要能在电脑和常见手机/平板浏览器使用，并尽量离线可用。
- 文轩不会写代码，界面用白话，不要命令行或技术术语。

## 硬约束
- **0 元**：不买域名、不开通付费套餐、不绑卡付费。若账号同步或托管必须花钱，或必须让文轩先注册某个免费云账号，立刻停下来，把原因和可选方案写进验收文档并结束本轮，等待拍板。不得擅自注册付费项或产生费用。
- 不删用户数据；不要改公考错题本仓库。
- 真题原句只使用可公开检索到的材料，不要去付费题库爬取或拷贝整套课程；验收里写来源。不要把密钥写进仓库。

## 实现提示（供你选择，不指定技术栈）
- 需要登录、跨设备同步、离线后回写，静态 GitHub Pages 单独不够，需有可 0 元使用的后端或免费 BaaS；先登录一次后的数据要能落在本机（如 IndexedDB），有网再同步。
- 间隔重复按常见做法即可（会的拉长间隔，模糊/忘记缩短或重来；新学与复习分堆）。
- 产品可暂用目录名 `yanyu-cishu`，不要花时间起商业名。

## 最小可交（做到即停）

2. 上述账号、词库、计划、两种练习模式、易混组、错词本、打卡与统计均能走通主路径。

4. 若已有可推送的 0 元托管且不需额外账号授权，可发布；否则不要强行付费发布。

完成后退出会话。过程不逐步报文轩。
